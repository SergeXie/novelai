# MySQL 独立定时备份常用命令

独立备份工具目录：

```text
D:\DatabaseBackupTool\scripts\backup\
```

备份文件目录：

```text
D:\DatabaseBackupTool\novelAi\backups\
```

## 文件说明

```text
D:\DatabaseBackupTool\
├── scripts\backup\
│   ├── backup-mysql.ps1
│   ├── install-backup-task.ps1
│   ├── restore-mysql.ps1
│   ├── show-backup-status.ps1
│   ├── start-backup-monitor.cmd
│   └── backup.env
└── novelAi\
    ├── backups\
    └── logs\
```

- `backup-mysql.ps1`：立即执行一次数据库备份。
- `install-backup-task.ps1`：安装或更新每天执行的 Windows 定时任务。
- `restore-mysql.ps1`：把 `.sql.zip` 备份恢复到数据库，谨慎使用。
- `show-backup-status.ps1`：显示任务状态、最新备份和最近日志。
- `start-backup-monitor.cmd`：双击打开备份监控窗口。
- `backup.env`：数据库连接配置，包含密码，不要发送或提交到 Git。
- `novelAi\backups`：保存压缩后的数据库备份文件。
- `novelAi\logs`：保存备份执行日志。

以下任务管理命令需要在“管理员 PowerShell”中执行。

## 手动备份一次

```powershell
& "D:\DatabaseBackupTool\scripts\backup\backup-mysql.ps1" `
  -EnvFile "D:\DatabaseBackupTool\scripts\backup\backup.env" `
  -BackupRoot "D:\DatabaseBackupTool\novelAi" `
  -RetentionDays 30 `
  -MySqlDumpPath "D:\Dev\phpstudy_pro\Extensions\MySQL5.7.26\bin\mysqldump.exe"
```

## 立即启动定时任务

```powershell
Start-ScheduledTask -TaskName "novelAi-MySQL-Backup"
```

## 停止当前任务

```powershell
Stop-ScheduledTask -TaskName "novelAi-MySQL-Backup"
```

## 重启任务

```powershell
Stop-ScheduledTask -TaskName "novelAi-MySQL-Backup"
Start-Sleep -Seconds 2
Start-ScheduledTask -TaskName "novelAi-MySQL-Backup"
```

## 暂停每天自动备份

```powershell
Disable-ScheduledTask -TaskName "novelAi-MySQL-Backup"
```

## 恢复每天自动备份

```powershell
Enable-ScheduledTask -TaskName "novelAi-MySQL-Backup"
```

## 查看任务状态

```powershell
Get-ScheduledTask -TaskName "novelAi-MySQL-Backup"
Get-ScheduledTaskInfo -TaskName "novelAi-MySQL-Backup"
```

`LastTaskResult` 为 `0` 表示上次执行成功；`267009` 表示任务正在运行。

## 查看备份日志

```powershell
Get-Content "D:\DatabaseBackupTool\novelAi\logs\backup.log" -Tail 20
```

## 打开监控窗口

双击：

```text
D:\DatabaseBackupTool\scripts\backup\start-backup-monitor.cmd
```

关闭监控窗口不会停止后台定时备份。

## 删除定时任务

```powershell
Unregister-ScheduledTask -TaskName "novelAi-MySQL-Backup"
```
