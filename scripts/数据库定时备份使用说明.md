# Windows MySQL 定时备份使用说明

项目提供了以下脚本：

```text
scripts\backup\backup-mysql.ps1          执行数据库备份
scripts\backup\install-backup-task.ps1  安装 Windows 定时任务
scripts\backup\restore-mysql.ps1         恢复数据库备份
```

备份脚本使用 MySQL 官方的 `mysqldump.exe`。当前服务器上的默认位置为：

```text
C:\Program Files\MySQL\MySQL Server 8.0\bin\mysqldump.exe
```

## 一、在项目中手动执行备份

打开 PowerShell：

```powershell
cd D:\Workspace\novelAi

.\scripts\backup\backup-mysql.ps1 `
  -BackupRoot "D:\DatabaseBackups\novelAi" `
  -RetentionDays 30 `
  -MySqlDumpPath "C:\Program Files\MySQL\MySQL Server 8.0\bin\mysqldump.exe"
```

数据库地址、端口、用户名、密码和数据库名读取项目根目录 `.env` 中的：

```env
DATABASE_URL=mysql+aiomysql://用户名:密码@服务器地址:3306/数据库名
```

备份成功后生成：

```text
D:\DatabaseBackups\novelAi\backups\数据库名_日期时间.sql.zip
```

运行日志位于：

```text
D:\DatabaseBackups\novelAi\logs\backup.log
```

## 二、完全脱离项目执行

独立工具目录结构：

```text
D:\DatabaseBackupTool\
├── backup-mysql.ps1
├── install-backup-task.ps1
├── restore-mysql.ps1
└── backup.env
```

`backup.env` 内容：

```env
DATABASE_URL=mysql+aiomysql://用户名:密码@服务器地址:3306/数据库名
```

执行独立备份：

```powershell
& "D:\DatabaseBackupTool\backup-mysql.ps1" `
  -EnvFile "D:\DatabaseBackupTool\backup.env" `
  -BackupRoot "D:\DatabaseBackups\novelAi" `
  -RetentionDays 30 `
  -MySqlDumpPath "C:\Program Files\MySQL\MySQL Server 8.0\bin\mysqldump.exe"
```

参数说明：

- `EnvFile`：独立的数据库连接配置文件。
- `BackupRoot`：备份文件及日志的保存目录。
- `RetentionDays`：备份保留天数，超过该天数的旧备份会自动删除。
- `MySqlDumpPath`：`mysqldump.exe` 的完整路径。

## 三、安装每天凌晨 2 点执行的计划任务

以管理员身份打开 PowerShell，然后执行：

```powershell
& "D:\DatabaseBackupTool\install-backup-task.ps1" `
  -EnvFile "D:\DatabaseBackupTool\backup.env" `
  -DailyAt "02:00" `
  -BackupRoot "D:\DatabaseBackups\novelAi" `
  -RetentionDays 30 `
  -MySqlDumpPath "C:\Program Files\MySQL\MySQL Server 8.0\bin\mysqldump.exe"
```

计划任务名称：

```text
novelAi-MySQL-Backup
```

任务以 Windows `SYSTEM` 账户运行，即使没有用户登录也可以执行。

## 四、立即测试计划任务

```powershell
Start-ScheduledTask -TaskName "novelAi-MySQL-Backup"
Start-Sleep -Seconds 10
Get-ScheduledTaskInfo -TaskName "novelAi-MySQL-Backup"
```

查看最新日志：

```powershell
Get-Content "D:\DatabaseBackups\novelAi\logs\backup.log" -Tail 20
```

检查备份文件：

```powershell
Get-ChildItem "D:\DatabaseBackups\novelAi\backups" |
  Sort-Object LastWriteTime -Descending |
  Select-Object -First 5 Name, Length, LastWriteTime
```

`LastTaskResult` 等于 `0`，并且产生了新的 ZIP 文件，表示执行成功。

## 五、修改执行时间

重新运行安装命令并更改 `DailyAt`，例如每天凌晨 3:30：

```powershell
& "D:\DatabaseBackupTool\install-backup-task.ps1" `
  -EnvFile "D:\DatabaseBackupTool\backup.env" `
  -DailyAt "03:30" `
  -BackupRoot "D:\DatabaseBackups\novelAi" `
  -RetentionDays 30 `
  -MySqlDumpPath "C:\Program Files\MySQL\MySQL Server 8.0\bin\mysqldump.exe"
```

相同名称的计划任务会被更新。

## 六、恢复数据库

恢复操作会向 `.env` 或 `backup.env` 指定的数据库写入数据。执行前应停止应用写入，并再次确认目标数据库。

```powershell
& "D:\DatabaseBackupTool\restore-mysql.ps1" `
  -BackupZip "D:\DatabaseBackups\novelAi\backups\数据库名_2026-08-03_020000.sql.zip" `
  -EnvFile "D:\DatabaseBackupTool\backup.env" `
  -MySqlPath "C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe"
```

根据提示输入：

```text
RESTORE
```

脚本才会开始恢复。

## 七、保护数据库配置

`backup.env` 中包含数据库密码。以管理员身份执行以下命令，只允许 `SYSTEM` 和管理员读取：

```powershell
icacls "D:\DatabaseBackupTool\backup.env" /inheritance:r
icacls "D:\DatabaseBackupTool\backup.env" /grant:r "SYSTEM:F" "Administrators:F"
```

不要把 `backup.env` 提交到 Git，也不要通过聊天或邮件发送该文件。

## 八、常见问题

### 找不到 mysqldump.exe

确认文件是否存在：

```powershell
Test-Path "C:\Program Files\MySQL\MySQL Server 8.0\bin\mysqldump.exe"
```

如果返回 `False`，查找实际位置：

```powershell
Get-ChildItem "C:\Program Files\MySQL" -Filter "mysqldump.exe" -Recurse
```

然后把命令中的 `MySqlDumpPath` 改成实际路径。

### PowerShell 禁止运行脚本

可以在当前 PowerShell 窗口临时放行：

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
```

关闭该窗口后设置自动失效。

### 查看任务执行失败原因

```powershell
Get-ScheduledTaskInfo -TaskName "novelAi-MySQL-Backup"
Get-Content "D:\DatabaseBackups\novelAi\logs\backup.log" -Tail 50
```
